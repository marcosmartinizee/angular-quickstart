How to get your OCI credentials:

  1. Log in to Oracle Cloud Console
  2. Click on your profile icon → User Settings
  3. Under "Resources", click "API Keys"
  4. Click "Add API Key" and download the private key
  5. Copy the configuration values shown after adding the key
  6. Find your Compartment OCID in Identity → Compartments
